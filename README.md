## Mean , Median and Mode
Mean, median and mode are '_Measures of central tendency_' in statistics.
**Mean**
The mean is the same as the average value of a data set and is found using a calculation. 
 1. Add up all data values to get the sum
 2. Count the number of values in your data set
 3. Divide the sum by the count
 4. The mean is the same as the average value in a data set.

**Mean Formula**
'_The mean x̄ of a data set is the sum of all the data divided by the count n_'.

**Median**
The median is the central number of a data set. 
 1. Arrange data values from lowest to highest value
 2. The median is the data value in the middle of the set
 3. If there are 2 data values in the middle the median is the mean of those 2 values.

**Mode**
The mode is the number in a data set that occurs most frequently.
